## 🎯 Vision
To master competitive programming through consistent practice and logical excellence, aiming for NOI gold proficiency over an 18-month journey.

## 📂 Repository Structure
- **/Phase_1**: Foundation training focusing on C++ STL, Big O complexity, and basic algorithms.
- **/doc**: Learning materials, CPH (Competitive Programmer's Handbook) notes, and reference guides.
- **index.html**: A personalized interactive training dashboard to track syllabus mastery and session progress.
